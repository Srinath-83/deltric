#  Deltric – Electrical Company Website

Deltric is a modern, high-performance electrical company website built using **React** and **Astro**.  
The website showcases electrical products, professional services, and company information with a clean, responsive, and scalable architecture.

---

##  Tech Stack

-  React – Component-based UI development
-  Astro – Fast static site generation
-  CSS / Tailwind (if used) – Styling
-  Responsive Design – Mobile-friendly layout

---

##  Features

-  Company profile and introduction
-  Electrical product showcase
-  Services section
-  Contact page
-  Fully responsive design
-  Optimized performance using Astro
